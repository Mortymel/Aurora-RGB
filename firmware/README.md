# Directorio heredado de firmware

Este directorio contiene el firmware anterior. El firmware actual de Aurora es **LEDWeb 1.3**, ubicado en [ledweb/firmware/LEDWeb](../ledweb/firmware/LEDWeb).

Usa el [web flasher actual](https://mortymel.github.io/Aurora-RGB/) o consulta [compilación de LEDWeb](../docs/FIRMWARE-PLAN.md). No mezcles la API ni el aprovisionamiento del código de este directorio con Aurora.
