Añadir ESP32

¿Es una ESP32 nueva? Empieza aquí
  1. Instala el firmware LEDWeb correspondiente a tu chip.
  2. Conecta el teléfono a la red LEDWeb-… que crea la placa. La clave inicial es tiraesp32, salvo que la hayas cambiado al compilar.
  3. Abre http://192.168.4.1. Usuario admin, clave inicial tiraesp32. En Wi-Fi, guarda el nombre y contraseña de tu red de 2,4 GHz.
  4. Vuelve a conectar el teléfono a tu Wi-Fi habitual. Busca la IP de la ESP32 en el router o el monitor serie.
  5. Vuelve aquí y escribe esa IP. Teléfono y ESP32 deben estar en la misma red.
En esta demostración se crea otro controlador simulado. No se comprueba ni se contacta esa IP real. No necesitas conectar una placa para probar el flujo.

Home Assistant / MQTT

MQTT conectado · simulado
¿Dónde consigo estos datos?
  1. En Home Assistant OS: Ajustes → Apps/Complementos → Mosquitto broker. Instálalo e inícialo.
  2. Crea un usuario, por ejemplo tira_led, en Ajustes → Personas → Usuarios, con una contraseña propia. Activa el modo avanzado de tu perfil si no aparece Usuarios.
  3. Consulta la IP local del equipo en Ajustes → Sistema → Red o en el router. Si Mosquitto está ahí, esa es la IP del broker.
  4. En Ajustes → Dispositivos y servicios, configura la integración MQTT y su descubrimiento.
  5. Aquí introduce esa IP, puerto 1883 y el usuario y contraseña creados. El dispositivo aparecerá como Tira LED.

Si ya tienes otro broker, usa sus datos. No uses el puerto web 8123, la contraseña Wi-Fi ni el nombre interno core-mosquitto.

Servidor vacío desactiva MQTT. La conexión del firmware usa la red local, sin TLS.

Se simula el estado MQTT. No se conecta a un broker real.
