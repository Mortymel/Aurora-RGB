MORTY'S LED

Instalar firmware

Conecta tu ESP32-WROOM-32 por USB para instalar el controlador de tus tiras LED. Diseñado para el mismo estilo de Morty's LED en Android.

ESP32-WROOM-32 · Tiras RGB direccionables

Firmware experimental · v0.3.0-dev · Cantidad configurable desde Android: 1–1024 píxeles por controlador. 12 efectos, brillo y velocidad, control WiFi local y MQTT opcional.

Necesitas Chrome o Edge de escritorio con Web Serial. Abre esta página mediante HTTPS.

La instalación puede borrar el firmware y la configuración existente.

Antes de empezar

  1. Comprueba que la tira RGB utilice un protocolo compatible con WS2812B y orden GRB. La cantidad se introduce al añadir la ESP32 en Android; no hay una longitud fija.
  2. Desconecta la tira LED durante el flasheo inicial.
  3. Conecta la placa con un cable USB de datos.
  4. Abre este instalador desde una web HTTPS con firmware.bin en la misma carpeta.
  5. Después, conecta al punto de acceso MortysLED-XXXX y abre 192.168.4.1/setup para configurar WiFi.
  6. En Android, pulsa Añadir controlador, introduce nombre, IP y cantidad de LED/píxeles. Si tu tira agrupa LED, introduce la cantidad de grupos direccionables. Puedes cambiarla en Editar controlador.

Prototipo de desarrollo: el punto de acceso inicial no tiene contraseña y el HTTP local no tiene autenticación. No utilizar en redes públicas ni en instalaciones críticas.
